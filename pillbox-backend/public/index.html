Test lid

Needs Chrome or Edge, and the dashboard opened at http://localhost:4000 on a PC or laptop with Bluetooth. After you change a medicine's time or compartment, the schedule is re-sent to the box automatically while it is connected.

How it connects

Your ESP32 sends this key in an X-Device-Key header on every request. It polls GET /api/device/state every ~30 seconds to see which compartments should unlock right now (based on today's schedule and each medicine's compartment number), and calls POST /api/device/ack with { "compartment": N } whenever the button on that compartment is pressed — which marks the dose taken here automatically.

Find your PC's local IP address (Command Prompt → ipconfig → "IPv4 Address") and use http://YOUR-PC-IP:4000 as the server address in the firmware — not localhost, since that would point the ESP32 at itself.
